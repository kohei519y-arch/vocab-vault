# ステップ6 課金・法務 実践ガイド
## （開業手続き・特定商取引法・Stripe本番設定・法務チェック）

Vocab VaultのProプラン（月額課金）を有料提供し、正式に商用ローンチするための実務マニュアルです。

---

## 1. 個人事業の開業手続き

日本国内で有料SaaSを個人運営する場合、税務上の手続きを行うことで節税（青色申告控除等）が可能になります。

### (1) 提出する書類（税務署へ提出、e-Taxまたは郵送/持参）
1. **個人事業の開業・廃業等届出書（開業届）**
   - **提出時期**: 事業開始日から1ヶ月以内。
   - **職業名**: 「Webサービス運営」「ソフトウェア開発」「情報通信業」等。
   - **屋号**: 「Vocab Vault」または屋号なしでも可。
   - **作成ツール**: 「freee開業」や「マネーフォワード クラウド開業」を利用すれば、数問の質問に答えるだけで無料でPDFが自動生成され、スマホマイナンバーカード送信も可能です。
2. **所得税の青色申告承認申請書**
   - **提出時期**: 開業日から2ヶ月以内（またはその年の3月15日まで）。
   - これを提出することで、最大65万円（電子申告時）または55万円の青色申告特別控除が受けられます。

### (2) 事業用銀行口座とクレジットカードの準備
- 個人の私用生活口座と分けるため、事業専用のネット銀行口座（住信SBIネット銀行、GMOあおぞらネット銀行、楽天銀行など）を開設しておくと、Stripeの売上振込や経費管理が非常にスムーズになります。

### (3) インボイス制度（適格請求書発行事業者）の判断
- Vocab Vaultは **B2C（一般個人学習者向け）** サービスです。法人が経費精算でインボイスを要求することは稀であるため、初年度や売上1,000万円未満の間は **免税事業者のままで開始しても問題ありません**。

## 3. Stripe 本番環境への移行手順

現在コードにはテスト用およびプレースホルダーの設定が施されています。本番決済を受け付けるための手順です。

### (1) Stripe アカウントの本番有効化
1. [Stripeダッシュボード](https://dashboard.stripe.com/) にログインし、「アカウントを有効化」を選択。
2. 事業形態（個人事業主）、氏名、住所、振込先銀行口座を登録。
3. ウェブサイトURLには、Vocab Vaultの本番公開URL（PWAサイト）を入力。
4. クレジットカード明細書に表示される表記（例: `VOCABVAULT`）を設定。

### (2) Stripeで「Proプラン（定期支払い商品）」を作成
1. Stripeダッシュボード > **商品カタログ (Products)** > **「商品を追加」** をクリック。
2. **商品名**: `Vocab Vault Proプラン`
3. **説明**: `語源・概念史AI無制限生成、詳細例文・同義語拡張、高速クラウド同期`
4. **料金体系**: `定期支払い (Recurring)`
5. **請求期間**: `毎月 (Monthly)`
6. **価格**: `¥980`
7. 作成後、価格ID（例: `price_1Pxxxxxx...`）をコピー。

### (3) Stripe Customer Portal（顧客ポータル）の有効化
1. Stripeダッシュボード > 設定 > **「カスタマーポータル (Customer portal)」** を開く。
2. 「ポータルを有効にする」をオン。
3. 顧客に許可するアクションとして以下を有効化：
   - サブスクリプションの解約を許可
   - 支払い方法の更新（カード変更）を許可
   - 請求書の履歴ダウンロードを許可
4. 規約・プライバシーポリシーのURL、サービスロゴを設定して「保存」。

### (4) Supabase Secrets の環境変数設定（本番キーの配備）
Supabase CLI を用いて、本番環境のキーを安全にEdge Functionsへ登録します。

```bash
# Stripe 本番APIキーの設定
npx supabase secrets set STRIPE_SECRET_KEY="sk_live_..."

# Stripe Webhookエンドポイントの署名シークレット設定
npx supabase secrets set STRIPE_WEBHOOK_SECRET="whsec_..."

# 上記で作成した月額ProプランのPrice ID
npx supabase secrets set STRIPE_PRO_PRICE_ID="price_1P..."

# 成功時/キャンセル時のリダイレクト先本番URL
npx supabase secrets set SITE_URL="https://your-domain.com"
```

### (5) Stripe Webhook の登録
1. Stripeダッシュボード > 開発者 > **Webhooks** > **「エンドポイントを追加」**。
2. **エンドポイントURL**:
   `https://<あなたのSupabaseプロジェクトID>.supabase.co/functions/v1/stripe-webhook`
3. **受信するイベント**:
   - `checkout.session.completed` （初回購入完了時）
   - `customer.subscription.updated` （プラン変更・更新時）
   - `customer.subscription.deleted` （解約・キャンセル時）
4. 登録後、「署名シークレット」を表示し、上記の `STRIPE_WEBHOOK_SECRET` に設定。

## 4. 利用規約・プライバシーポリシーの専門家レビュー手順

本リポジトリに含まれる以下の2つのドキュメントは、標準的なSaaSの法務条項を満たしたドラフト（草案）です：
- `docs/TERMS_OF_SERVICE.md` （利用規約）
- `docs/PRIVACY_POLICY.md` （プライバシーポリシー）

### (1) レビューを依頼する際のポイント
商用サービスとして正式公開する前に、IT・Webサービスに詳しい弁護士または行政書士にリーガルチェックを依頼することを推奨します。

依頼時のチェック観点：
1. **生成AI特有の免責条項**:
   - Gemini APIが生成した語源・概念史・例文等の記述に誤りやハルシネーション（幻覚）が含まれていた場合でも、運営者が責任を負わない免責（第7条）が法的に有効か。
2. **サブスクリプションの中途解約・返金不可条項**:
   - 消費者契約法第9条（平均的損害額を超える違約金の無効）等に抵触しない表現になっているか。
3. **アカウント停止およびデータ削除規定**:
   - クォータの意図的な不正迂回やスクレイピング行為に対する即時利用停止権限（第6条）。

### (2) 手軽な専門家チェックの依頼先
- **ココナラ（弁護士・行政書士カテゴリ）**: 1〜3万円程度でWebサービス規約のリーガルチェック・修正提案をしてくれる専門家が多数存在します。
- **クラウドワークス / ランサーズ**: 「Webサービス利用規約 リーガルチェック」で公認資格者（弁護士・行政書士）を指定して発注。
- **IT法務専門の法律事務所**: 初回無料相談やスポット契約でチェック可能。
