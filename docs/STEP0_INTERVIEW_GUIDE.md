## 2. ターゲット層の選定とリクルーティング方針

### ターゲットA：難関外国語資格・学術論文読者（客単価・継続率高）
- **属性**: 大学院生・研究者、英検1級 / DALF C1 / Goethe C1 受験者、哲学者・社会科学研究者。
- **課題**: 単語の辞書的定義だけでは文脈が読み解けない。「なぜその意味になるのか」という概念史・語源の文脈が必要。
- **接触チャネル**: X（旧Twitter）の語学・学術系コミュニティ、大学の大学院生ネットワーク、note/Zennの語学学習記事読者。

### ターゲットB：マルチリンガル学習者（英仏独の複言語話者・学習者）
- **属性**: 英語を習得済みで、第2外国語としてフランス語やドイツ語を学んでいる層。
- **課題**: 言語ごとにバラバラに単語帳を作っており、語根や印欧祖語（PIE）レベルの共通性を活かしきれていない。
- **接触チャネル**: 多言語学習Discordコミュニティ、語源マニアの勉強会、語学系YouTuber/ブロガーのフォロワー。

## 3. インタビュー質問票（ヒアリング・スクリプト）

### パート1：現状の学習フローと課題（10分）
1. 「現在、英語・フランス語・ドイツ語の語彙学習はどのようなツールや方法で行っていますか？（Anki、紙の単語帳、自作ノートなど）」
2. 「難解な抽象語や専門用語（例：institution, aliénation, Aufhebung等）に出会ったとき、どのように意味やニュアンスを調べていますか？」
3. 「語源や成り立ちを調べるとき、不便に感じることや諦めてしまうポイントは何ですか？（時間がかかる、辞書によって記述が異なる、捏造が怖い等）」

### パート2：プロトタイプの体験とフィードバック（15分）
1. *（実際にVocab Vaultを操作してもらい、自分が最近調べた単語を2〜3語登録してもらう）*
2. 「生成された解説（歴史・専門補足、コアイメージ、印欧祖語タグ）を見て、どう感じましたか？」
3. 「『同語根』や『3言語同族候補』のリンクをタップしてみて、どのように感じますか？」
4. 「Wiktionary裏付けラベルや、長文・画像OCR機能について、日常の学習で使えそうですか？」
5. 「逆に、分かりにくかった点や、物足りない・不要だと感じた部分はどこですか？」

### パート3：価格受容性テスト（PSM分析質問）（5分）
以下の4つの質問を投げかけ、適正価格帯を割り出す。
1. **高すぎる（Too Expensive）**: 「いくら以上だと、どんなに良くても絶対に購入・契約しないと感じますか？」
2. **安すぎて不安（Too Cheap）**: 「いくら以下だと、品質や正確性に不安を感じて使いたくないと感じますか？」
3. **高いが検討する（Expensive）**: 「いくらから『ちょっと高いけれど、価値を考えれば検討する』と感じますか？」
4. **お得・割安（Cheap）**: 「いくらだと『非常にリーズナブルで、迷わずすぐ契約する』と感じますか？」

## 4. アプリ内フィードバック収集の運用ルール

1. **常設ボタンの配置**:
   - サイドバー下部およびカード詳細に「フィードバック／ご意見」ボタンを常設。
2. **「ヒアリング協力者募集」のインセンティブ**:
   - 「30分のオンラインインタビューにご協力いただいた方には、本アプリのProプラン1年間無料権（またはAmazonギフト券1,500円）を進呈」という案内をモーダルに掲載。
3. **ログ収集（匿名）**:
   - 登録された単語の言語比率（EN/FR/DE）、OCR抽出機能の利用頻度、赤シートモードの利用率を集計し、機能の統廃合の判断材料とする。
