# 【note / Zenn 掲載用記事全文】
## Ankiの挫折者が、印欧祖語と忘却曲線を融合させた最強の語源単語帳Webアプリを作った話

### はじめに：なぜ私たちは英単語を覚えられないのか？

「英単語帳を何周しても、試験や洋書の前で頭が真っ白になる」
「単語と日本語訳の1対1の丸暗記に耐えられない」

英語を本気で学ぼうとした人なら、誰もがこの絶望を味わったことがあるはずです。

人間の脳は、**「文脈のない孤立した記号」を急速に忘却するように設計されています**。
一方で、大ベストセラー『英単語の語源図鑑』が証明したように、「単語のルーツ（語源）」を知ると、霧が晴れるように納得できます。

しかし、紙の本には致命的な弱点がありました。
**「読んだ瞬間は感動するが、分散復習（SRS）ができないため、2週間後には結局忘れてしまう」** という問題です。

世界中の学習者が愛用する分散学習アプリ『Anki』もありますが、
- UIが無骨で設定が極めて難解
- 語源やコアイメージのカードを1語ずつ自分で調べるのに膨大な時間が溶ける
という高いハードルがありました。

「語源図鑑の圧倒的な納得感」と「Ankiの科学的忘却曲線」、そして「Obsidianのような美しい知識ネットワーク」が1つになったツールがあれば、語学学習は一生モノの知的探求になるのではないか？

そう考え、個人開発でゼロから作り上げたのが、語源・概念史・語根ネットワーク単語帳**『Vocab Vault（ボキャブ・ヴォールト）』**です。

---

### Vocab Vault が目指した「暗記の脱構築」

Vocab Vault は、単なる「単語テストアプリ」ではありません。

#### 1. 印欧祖語（PIE）まで遡る「概念史」の自動深掘り
単語を登録すると、Gemini AI と Wiktionary 辞書データが連動し、紀元前数千年の印欧祖語（Proto-Indo-European）の語根、コアイメージ、歴史的変遷を一瞬で生成します。
例えば `inspect` を登録すると、語根 `*spek-`（見る）から、ラテン語 `spicere` を経て「中を覗き込む → 検査する」に至った概念の歴史が解き明かされます。

#### 2. 語根ネットワークの2Dインタラクティブ可視化
登録した単語は、HTML5 Canvas 2D による物理バネモデルでリアルタイムにクラスタリングされます。
同じ語根を持つ仲間（`inspect`, `respect`, `expect`, `spectacle`, `aspect`）が画面上で蜘蛛の巣のように結合し、1つの語根を覚えるだけで5〜10個の単語が芋づる式に定着します。

#### 3. 認知心理学「体制化効果」を組み込んだ次世代SRS
一般的なAnkiアルゴリズム（SM-2）をさらに進化させました。
- **語根密度連動ボーナス**: 語根ネットワークが密に結合した単語は記憶の干渉が少ないため、復習間隔を 1.08〜1.15倍 に最適伸長（過剰復習の防止）。
- **FSRS 相対期日超過率ソート**: 予定インターバルに対してどれだけ期日を超過しているかを動的計算し、いま最も想起確率が落ちている単語から優先出題。

#### 4. 本や書類をパシャッと撮るだけの「外カメラ直結OCR」
洋書やペーパーバック、資格試験の過去問を読んでいる最中に、スマートフォンで直接撮影するだけで、文脈付きで重要単語を自動抽出・一括登録できます。

### こだわりの技術スタック：なぜ「Zero-Build & Local-First」なのか？

個人開発Webアプリで最も恐ろしいのは、「フレームワークのバージョンアップによる陳腐化」と「サーバー維持費の肥大化によるサービス終了」です。

ユーザーの大切な学習資産を一生守るため、以下のアーキテクチャを採用しました：

1. **Zero-Build Step (No Webpack / No npm run build)**:
   ビルドツール不要の純粋なモジュラー JavaScript (ES6+)。ダウンロードした zip ファイルを展開してブラウザで開くだけで、100% オフラインで動作します。
2. **IndexedDB を単一の信頼できる情報源（SSOT）とする二重永続化**:
   LocalStorageの5MB制限や iOS Safari PWA の7日間パージ問題を解決するため、IndexedDB をプライマリとし、LocalStorage をミラーとするハイブリッド構成。
3. **CSS `content-visibility: auto` による仮想描画**:
   単語数が 5,000 語を超えても、画面外のカード描画計算をブラウザネイティブでスキップ。120fpsのシルキースムーズなスクロールを実現。
4. **完全なデータポータビリティ**:
   解約後も全機能がローカルで永久に無料動作。いつでもワンクリックで Anki 用 TSV や Obsidian 用 Markdown、JSON にエクスポート可能。
