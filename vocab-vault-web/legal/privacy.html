プライバシーポリシー

最終更新日: 2026年10月18日

Vocab Vault 運営者（以下「当方」）は、語学学習サービス「Vocab Vault」（以下「本サービス」）におけるユーザーの個人情報の取扱いについて、以下のとおりプライバシーポリシー（以下「本ポリシー」）を定めます。

1. 収集する利用者情報

本サービスにおいて収集する利用者情報は以下のとおりです：

  • アカウント情報: メールアドレス、暗号化パスワード、認証トークン
  • 学習進度データ: 登録単語、復習履歴、FSRS学習パラメータ、語根マップデータ
  • 決済情報: クレジットカード決済は決済代行業者（Stripe, Inc.）が直接処理し、当方のサーバーにはクレジットカード番号やセキュリティコードは一切保存されません。
  • 端末・利用環境情報: IPアドレス、ブラウザ種別、OS種別、アクセスログ

2. 利用目的

収集した情報は、以下の目的で利用されます：

  • 本サービスの提供、認証、およびクラウド同期の維持
  • 個人の忘却曲線（FSRS / SM-2）に最適化された復習スケジュールの算出
  • サブスクリプション課金処理および顧客サポートの提供
  • サービスの不正利用防止およびセキュリティの維持

3. 第三者提供および外部委託

当方は、法令に基づく場合を除き、ユーザーの同意なく個人情報を第三者に提供しません。ただし、本サービスの円滑な運営のため、以下の信頼できるクラウドインフラにデータ処理を委託しています：

  • Supabase, Inc.: データベースホスティングおよびユーザー認証基盤（暗号化通信および Row Level Security 適用）
  • Stripe, Inc.: 決済代行およびサブスクリプション管理（PCI DSS レベル1準拠）
  • Google Cloud (Gemini API): 単語解説・語源生成処理（学習データとしての恒久保持は行われません）

4. データの管理とアカウント削除

ユーザーは、アプリ内の設定画面「アカウント削除」ボタンより、いつでも自己のアカウントおよびクラウド上の全学習データを即座に完全抹消（Permanent Deletion）することができます。連携されたStripeサブスクリプションも自動解約されます。

5. Cookieおよびローカルストレージの利用

本サービスは、オフラインファースト動作および学習データの高速読み込みのため、ブラウザの IndexedDB および localStorage を利用します。トラッキング目的の第三者広告Cookieは一切使用しておりません。

6. お問い合わせ窓口

プライバシーポリシーに関するご質問や開示等の請求は、アプリ内のお問い合わせ・フィードバック送信フォーム、またはサポートメール窓口までご連絡ください。
