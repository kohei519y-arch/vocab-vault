GUIDE

Vocab Vault ガイドツアー

1. 印欧祖語（語根）による芋づる式暗記

単語を単体で丸暗記する非効率から脱却しましょう。英語・仏語・独語などの主要語彙は、数千年前の「印欧祖語（Proto-Indo-European）」の共通語根から派生しています。

例: 語根 *sta- (立つ・据える・固定する)
・stand: その場に立つ
・statue: 固定された彫像
・substance: sub(下で) + sta-(立つもの) → 実質・本質
・constant: con(共に) + sta-(立ち続ける) → 不変の
・destination: de(完全に) + sta-(据えられた先) → 目的地

語根と形態素（接頭辞・接尾辞）を理解することで、最難関レベルの未知の単語に出会っても、核となる概念を瞬時に読み解くことが可能になります。

2. 次世代忘却曲線（FSRS-4.5）と適応復習

旧来のSM-2アルゴリズムを超えた最新の4変数モデル（安定度・難易度・経過時間・忘却臨界点）を搭載。あなたの脳の想起リズムに完全に適応します。

・形態素・語根連動ボーナス:
同一語根の単語を連続して正解すると、ネットワーク全体の復習間隔が自動で延伸され、復習コストを科学的に圧縮します。
・認識 ＆ Cloze（穴埋め産出）モード:
意味の想起だけでなく、文脈の穴埋めタイピングで発信語彙力を鍛錬。タイポや活用形の揺らぎも自動判定します。

「復習期日が近づいた語」のみを自動抽出するため、無駄な復習に時間を奪われることはありません。

3. あなたの好みに合わせた表示モード

単語帳の初期表示スタイルを選択してください。この設定はツールバーからいつでもワンタップで変更可能です。
